# Чек-лист рев'ю PR (спека ↔ код)

PR: <посилання> · Спека: <посилання> · Рев'ювер: <ім'я>

## Відповідність спеці
- [ ] PR посилається на спеку і конкретні AC
- [ ] Усі заявлені AC реалізовані
- [ ] Немає змін поза скоупом (порівняй з out of scope)
- [ ] Edge cases зі спеки оброблені

## Тести
- [ ] Кожен AC з PR має тест
- [ ] Жоден тест не вимкнено і не пропущено (`skip`, `only`, `xit`, закоментовані)
- [ ] Тести перевіряють поведінку, а не підлаштовані під код
- [ ] CI зелений

## Трюки агента
- [ ] Немає заглушок/TODO замість реалізації
- [ ] Немає хардкоду значень, які мали б прийти з даних
- [ ] Немає «тихого» ковтання помилок

## Спека
- [ ] Якщо поведінка змінилась, спеку оновлено раніше за код (або в цьому ж PR)

## Висновок
Approve / Request changes. Коментарі: де → що не так → яку вимогу порушено.
