# Spec Owner: курс самонавчання spec-driven development

Курс для людини без досвіду в ІТ, яка хоче працювати **spec owner'ом (AI-native BA)** у командах, що розробляють софт за підходом spec-driven development (SDD).

**Spec owner** відповідає за те, *що і навіщо* будуємо: пише й підтримує вимоги та acceptance criteria, рев'ює план і результат AI-агента на відповідність вимогам і стежить, щоб специфікація й код не розходилися. *Як* будуємо (архітектура, технічний план) вирішує інженер, а spec owner рев'ює його рішення.

## Як влаштований курс

- **12 тижнів**, ~20 годин на тиждень (5 днів по ~4 год). Повний план: [ROADMAP.md](ROADMAP.md)
- **6 модулів:** основи → git → вимоги → SDD-інструменти → тести й рев'ю → процес і капстоун
- Кожен тиждень має однакову структуру: навіщо → що прочитати → план по днях → що здати → самоперевірка → критерії «готово» → ретро
- **Тижні 1–2** проходять у вебтренажері, git на цьому етапі не потрібен. **З тижня 3** уся робота ведеться в цьому репозиторії через гілки й PR.

## Як почати

1. Прочитай [ROADMAP.md](ROADMAP.md), щоб побачити весь шлях.
2. Налаштуй Claude-ментора за [`mentor/SETUP.md`](mentor/SETUP.md).
3. Відкрий [тиждень 1](weeks/01-how-software-is-built/README.md).
4. Наприкінці кожного тижня заповнюй ретро і відмічай прогрес у трекері.

## Правила курсу

- **Спершу спека, потім код.** Завжди, навіть у навчальних проєктах.
- **Не проси агента зробити завдання замість тебе.** Проси перевірити, поставити питання, знайти пропуски.
- **Кожна помилка агента — це підказка, де дірка в спеці.** Записуй їх у журнал.
- **Застряг більше ніж на годину — спитай ментора.**
