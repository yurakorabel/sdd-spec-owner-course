## План по днях

### День 1 — Рівні тестів
- [ ] unit / integration / e2e: що кожен перевіряє
- [ ] Як запустити тести в проєкті
- [ ] Прочитати 5 тестів і пояснити, що вони перевіряють

### День 2 — Читання тестів
- [ ] Назва, вхідні дані, очікування
- [ ] Чи відповідає тест критерію з спеки?
- [ ] Знайти критерій без тесту

### День 3 — Матриця трасування
- [ ] Заповнити `templates/traceability-matrix.md`: критерій → тест → задача → PR
- [ ] Попросити агента дописати тести для непокритих критеріїв
- [ ] Перевірити ці тести

### День 4 — Ламаємо
- [ ] Навмисно зламати фічу
- [ ] Знайти, який тест упав і чому
- [ ] Сформулювати агенту точну задачу на виправлення

### День 5 — Підсумок
- [ ] Здати PR
- [ ] Ретро
