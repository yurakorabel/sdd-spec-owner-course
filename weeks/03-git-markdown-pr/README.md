## План по днях

### День 1 — Markdown
- [ ] Заголовки, списки, таблиці, чекбокси, посилання, блоки коду
- [ ] Переписати `work/glossary.md` у гарний Markdown
- [ ] Переглянути, як він рендериться на GitHub

### День 2 — Git локально
- [ ] clone, status, add, commit, log
- [ ] Що таке diff і як його читати
- [ ] Перенести свої файли тижнів 1–2 у репо комітами

### День 3 — Гілки й PR
- [ ] branch, switch, push
- [ ] Відкрити PR, написати опис за шаблоном
- [ ] Заповнити чек-лист PR

### День 4 — Рев'ю й конфлікти
- [ ] Коментарі до рядків, approve / request changes
- [ ] Навмисно створити й розв'язати merge-конфлікт
- [ ] Пройти рев'ю від Claude-ментора

### День 5 — Структура репо
