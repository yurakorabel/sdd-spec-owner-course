## План по днях

### День 1 — Чек-лист рев'ю
- [ ] Розібрати `templates/pr-review-checklist.md`
- [ ] Все зі спеки зроблено? Нема зайвого? Edge cases покриті?
- [ ] Адаптувати чек-лист під себе

### День 2 — Трюки агентів
- [ ] Тест підлаштований під код
- [ ] Вимкнений або пропущений тест
- [ ] Заглушка замість реалізації, хардкод

### День 3 — Саботаж, частина 1
- [ ] Отримати 3 саботажні PR (`mentor/scenarios/sabotage.md`)
- [ ] Знайти розбіжності
- [ ] Звірити з розв'язкою

### День 4 — Саботаж, частина 2
- [ ] Ще 2 PR підвищеної складності
- [ ] Написати коментарі рев'ю так, як для інженера
- [ ] Звірити

### День 5 — Підсумок модуля 4
- [ ] Фінальна версія чек-листа
- [ ] Здати PR
- [ ] Ретро

## Що здати

Рев'ю 5 саботажних PR + власний чек-лист рев'ю

Як здати: гілка `week-10` → PR за шаблоном → рев'ю Claude-ментора (`mentor/`) → merge.

## Самоперевірка

- Як відрізнити зміну, потрібну для реалізації, від «зайвої»?
- Що перевірити, коли всі тести зелені?
- Як написати коментар, щоб його зрозуміли без дзвінка?

## Готово, коли

- [ ] Знайдено ≥ 4 з 5 закладених проблем
