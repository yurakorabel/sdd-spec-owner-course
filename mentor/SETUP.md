# Як налаштувати Claude-ментора

1. Створи в Claude новий **Project** з назвою «SDD Mentor».
2. У Project instructions встав вміст [`instructions.md`](instructions.md).
3. У Project knowledge додай:
   - `ROADMAP.md`
   - усі файли з `templates/`
   - усі файли з `mentor/rubrics/`
   - `GLOSSARY.md`
4. Кожен тиждень починай новий чат у цьому Project з фрази: «Тиждень N, день M». Ментор знатиме, що ти робиш.
5. Для рев'ю вставляй текст спеки або посилання на PR і пиши: «Рев'ю за рубрикою <назва>».
6. Сценарії з [`scenarios/`](scenarios/) запускай окремими чатами.
